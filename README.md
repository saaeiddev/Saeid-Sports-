# SAEID SPORTS

A production-oriented immersive 3D sports discovery experience built with Three.js/WebGL and designed for GitHub Pages.

## Features

- Real-time 3D sports arena with 25 interactive sports
- Cinematic camera transitions and dynamic lighting
- Interactive hover/tap sport selection
- Search and category filtering
- Sport detail tabs: overview, equipment, clothing, rules, skills and facts
- Real-world sports photography with graceful image fallbacks
- Mouse, touch and keyboard interaction
- Web Audio micro-sounds with explicit user toggle
- Responsive mobile rendering and adaptive pixel ratio
- Reduced-motion support and WebGL fallback
- GitHub Pages deployment workflow

## Deployment

The site is static and uses native ES modules plus Three.js from jsDelivr. GitHub Actions publishes the repository root to GitHub Pages.
